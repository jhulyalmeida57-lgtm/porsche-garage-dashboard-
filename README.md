🏎️ Porsche Garage | Dashboard de Vendas

Sobre o projeto

Dashboard interativa criada para o desafio da DIO, com foco na análise de vendas automotivas. A interface combina indicadores comerciais, gráficos e filtros com uma identidade visual esportiva inspirada no universo Porsche.

Perguntas de negócio

- Qual é a receita potencial representada pelas vendas?
- Quais modelos têm maior participação nos registros?
- Quais cidades concentram mais vendas?
- Qual é a situação das entregas?
- Como os indicadores mudam com os filtros?

Essas perguntas ajudam a explorar o desempenho comercial, a distribuição geográfica e o andamento das entregas.

Uso da IA e evolução do prompt

Utilizei o ChatGPT para gerar e refinar uma dashboard em HTML, CSS e JavaScript a partir de uma planilha de vendas Porsche.

Resumo do prompt inicial: criar uma dashboard de vendas Porsche com indicadores, gráficos e filtros interativos, usando uma identidade visual esportiva inspirada em filmes de carros animados.

Na evolução do projeto, refinei a identidade visual, adicionei cores escuras com detalhes em vermelho e amarelo, personagens automotivos originais, animações e melhorias de apresentação.

Utilizei o ChatGPT em uma conversa, de forma iterativa. Não utilizei um agente com skill específico nem o Canvas.

Tratamento da base de dados

A base contém 100 registros e apresenta datas inválidas em parte das linhas. Esses valores precisam ser tratados como ausentes ou excluídos das análises temporais para evitar conclusões incorretas. Também é importante interpretar corretamente preços, modelos, quilometragem e status de entrega.

Os valores apresentados representam os registros da base e não necessariamente valores efetivamente recebidos.
